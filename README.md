# Sword Art Online

**Sword Art Online** is a popular sci-fi anime about players trapped in a virtual reality MMORPG where dying in the game means dying in real life.

## Quick Details
* **Author:** Reki Kawahara
* **Genre:** Action, Sci-Fi, Fantasy
* **Main Characters:** Kirito and Asuna

## Main Story Arcs
1. **Aincrad** - Surviving the original death game.
2. **Fairy Dance** - Rescuing Asuna in Alfheim Online.
3. **Phantom Bullet** - Solving a mystery in Gun Gale Online.
4. **Alicization** - Exploring an advanced AI world.

### Fun Fact
Every single sound effect for the swords and magic in the anime was recorded using **real, heavy metal broadswords and shields** the sound team physically clashed real weapons together in a studio instead of using computer-generated audio.
